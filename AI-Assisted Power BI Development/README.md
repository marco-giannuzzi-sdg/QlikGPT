# AI-Assisted Power BI Development

Cartella dedicata alla demo di sviluppo Power BI assistito dall'AI, a partire da un mockup e da un progetto PBIP vuoto.

## Progetto iniziale

Caricare qui l'intero progetto salvato da Power BI Desktop:

- il file `.pbip`;
- la cartella `.Report`;
- la cartella `.SemanticModel`, se presente.

Il solo file `.pbip` rimanda alle cartelle del progetto e non contiene tutte le definizioni del report e del modello.

Il progetto costituirà la base per costruire la pagina dal mockup, tracciare le revisioni in GitHub e verificare il risultato in Power BI Desktop.
